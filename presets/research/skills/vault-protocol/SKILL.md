# Vault protocol（研究库协议）

适用于任何研究库，不假设固定机器路径。先读工作区的 `AGENTS.md`、`progress.md` 与 `governance/`。

## 加工链

素材 material（它说了什么）→ 观点 insight（提炼什么）→ 议题 issue（如何思考）→ 结论 conclusion（最终判断）。
素材状态按 `collected → read → digested → threaded → synthesized` 只升不降；每次晋升必须有证据并同步索引。

## 硬约束

- 外部事实优先引用官方文档、源码、原始数据；事实、推断、假设分开。
- 素材保留来源与定位；观点回链素材；议题记录历史；结论面向外部读者。
- 新内容先进入 `inbox/`，整理后再进入 `research/` 或 `projects/`。
- 触及索引、状态、链接后运行工作区提供的 consistency checker；失败如实汇报。
- 不把个人画像、机器路径、凭证写进共享方法 skill。
